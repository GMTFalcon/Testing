    How to use this workpaper

    A checklist of what to obtain for each SOC 2 common criterion, and a place to record what you found.

    Save the file after your first session, and after every session that follows. Your work is held in this browser only, so it will not follow you to another machine and it can be lost if browser data is cleared.

    Click Save as HTML. That downloads a fresh copy of this entire workpaper with your statuses, notes and attachments inside it, named after the client — for example Acme Corp SOC2.html. Keep that file in the engagement folder. Next session, open the saved file rather than the original and carry on where you stopped.

    Working through it

    1. Enter the client name, period and your initials at the top. The client name becomes the file name when you save.
    2. Pick a criterion from the index. Each one lists the evidence to obtain, how to test it, and the failures that commonly turn up there.
    3. Click an evidence item’s status to advance it as you go: not requested, requested, received, tested, exception.
    4. Open Notes beside any item to record what you saw, attach the evidence file, or add a link or path to where it is filed. The item shows a dot or a count once something is there.
    5. Set a conclusion for the criterion and record population, sample and exception detail in the notes at the bottom.

    Getting things out of it

    Download PBC list gives you a CSV of every evidence request with its status and your notes — that is the list you send the client. Download workpaper gives a Markdown summary of conclusions. Print produces a PDF of the criterion on screen, with notes expanded.

    Sharing and review

    Send the saved HTML file. It opens in any browser with nothing to install, so a reviewer needs no software and no account. If two people work separate copies, merge through the CSV exports rather than by swapping files.

    Two things to watch

    Attached files are embedded in the saved copy, so the file grows with what you attach. For large PDFs, add a link or path instead. Files over 8 MB are not embedded.

    If a saved file and this browser both hold work, the more recent of the two is loaded.
